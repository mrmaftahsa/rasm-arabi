# رسمة — RasmArabi 🎨

An original, free Arabic drawing-learning app for Android, built with Kotlin and Jetpack Compose.

- Arabic RTL user interface
- Eight categories and 48 unlocked beginner lessons
- Step-by-step practice with a touch drawing canvas
- Color palette, undo and clear
- Local drawing gallery and progress tracking
- No subscriptions or accounts

This is an early, original learning app and does not include assets or restricted content from any other drawing app.

## Build

Open this repository in Android Studio with JDK 17 and Android SDK 35, or use the GitHub Actions **Build Android APK** workflow to create a debug APK. Android Gradle Plugin 8.9.2, Kotlin 2.0.21, Gradle 8.11.1.

The initial project is an MVP; lessons are simple vector practice guides and may be expanded over time.
